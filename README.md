## 🛠️ Must-Have Developer Tools

* [BestJSON](https://bestjson.com/) – Free browser-based tools to format, validate, repair, compare, query, and convert JSON locally without uploading input.
* [AppScreen](https://appscreen.pro/) – Free browser tool for making App Store and Google Play screenshots for your mobile app, no sign-up needed.
* [HTTP Status Codes](https://bestlatestapps.com/tools/http-status-codes/) – Free reference for every HTTP status code from 100 to 599, with common causes and how to fix each one.
* VS Code – Code editor
* Git & GitHub – Version control
* Postman – API testing
* Figma – UI / UX design
* Chrome DevTools – Debugging

## 🤖 AI Tools for Developers (HOT 🔥)

* ChatGPT – Coding & explanations
* GitHub Copilot – AI pair programmer
* Claude – Long-form reasoning
* Perplexity – Research assistant
* Codeium – Free AI autocomplete
* Gemini - Powerful AI ( Recommended For Image Generating )
* GetYouTubeTranscript – YouTube video transcripts for AI summaries and notes
* [Kite](https://kite.new) – Design tool your AI agents share with your team: Claude, ChatGPT, Cursor or Codex draw editable UI layers via a hosted MCP server, then copy any frame as HTML, React or Tailwind. Free plan.
* [Scalekit](https://www.scalekit.com) – AI agent integrations platform and MCP gateway: lets the agents you build call tools in Gmail, Slack, GitHub and 1,100+ other apps on behalf of each user. Free plan.
